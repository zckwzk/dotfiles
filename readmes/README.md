# 📚 Dotfiles Documentation Directory (`readmes/`)

Selamat datang di direktori dokumentasi konfigurasi dotfiles Zakaniwa.  
Setiap komponen memiliki panduan terpisah yang merinci fungsi, plugin yang terpasang, daftar shortcut, dan petunjuk penggunaannya:

---

## 🗂️ Daftar Panduan Konfigurasi

| Komponen | Lokasi Dokumentasi | Ringkasan Isi |
| :--- | :--- | :--- |
| **🪟 Tmux** | [`readmes/tmux/README.md`](tmux/README.md) | Konfigurasi Tmux, panduan plugin (TPM, sensible, yank, resurrect, continuum), integrasi clipboard, dan daftar lengkap shortcut |
| **🐚 Bash & Helpers** | [`readmes/bash/README.md`](bash/README.md) | Arsitektur modular `.bashrc.d/`, perintah `dotfiles`, tab autocompletion, shortcut `df-*`, dan cara menambah alias baru |
| **🤖 Waydroid** | [`readmes/waydroid/README.md`](waydroid/README.md) | Perintah cepat Waydroid (`wd-multiwin`, `wd-freeze`, `wd-resume`, `wd-stop`) untuk mengelola Android di Wayland |
| **💻 Alacritty** | [`readmes/alacritty/README.md`](alacritty/README.md) | Konfigurasi font JetBrainsMono Nerd Font, mode maximized, pengaturan transparansi (opacity), dan padding |
| **⚡ Neovim (LazyVim)** | [`readmes/neovim/README.md`](neovim/README.md) | Struktur folder LazyVim, shortcut file picker, buffer management, cara menambah plugin baru, dan manajemen Mason LSP |

---

## 💡 Navigasi Cepat
Untuk membuka panduan di terminal, Anda bisa membaca file ini langsung menggunakan pager atau editor:
```bash
# Contoh membaca dokumentasi Tmux
less ~/readmes/tmux/README.md

# Atau buka di Neovim
nvim ~/readmes/tmux/README.md
```
