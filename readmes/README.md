# 📚 Dotfiles Documentation Directory (`readmes/`)

Welcome to Zakaniwa's dotfiles configuration documentation.  
Each component features a dedicated guide detailing its architecture, installed plugins, keybindings, and workflow tips:

---

## 🗂️ Configuration Guides

| Component | Guide Location | Summary |
| :--- | :--- | :--- |
| **🪟 Tmux** | [`readmes/tmux/README.md`](tmux/README.md) | Tmux config, TPM plugins (sensible, resurrect, continuum), and full shortcut reference |
| **🐚 Bash & Helpers** | [`readmes/bash/README.md`](bash/README.md) | Modular `.bashrc.d/` layout, `dotfiles` command, tab autocompletions, `df-*` aliases, and adding new scripts |

## 💡 Quick Terminal Access
To quickly read any guide in your terminal:
```bash
# Example: read Tmux documentation
less ~/readmes/tmux/README.md

# Or open in Neovim
nvim ~/readmes/tmux/README.md
```
